## Feature inventory
- Role-pack structure: "Twenty-three specialists and eight power tools, all slash commands, all Markdown" arranged as a sprint pipeline — Think → Plan → Build → Review → Test → Ship → Reflect — where each skill consumes the previous skill's artifact (`/office-hours` writes a design doc that `/plan-ceo-review` reads; `/plan-eng-review` writes a test plan that `/qa` picks up) [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Manager/reviewer persona ladder (§16.9 evidence): `/office-hours` YC-style product interrogation with six forcing questions; `/plan-ceo-review` CEO scope modes (Expansion/Selective/Hold/Reduction); `/plan-eng-review` eng-manager architecture lock (ASCII data-flow/state diagrams, test matrix); `/plan-design-review` senior designer rating each dimension 0–10 with AI-slop detection; `/plan-devex-review` DX lead with 20–45 forcing questions; `/review` staff-engineer production-bug finder with auto-fix; `/investigate` debugger under an "Iron Law: no fixes without investigation", stopping after 3 failed fixes; `/cso` security officer running OWASP Top-10 + STRIDE with an 8/10-confidence gate and independent finding verification; `/ship` release engineer; `/canary` SRE; `/retro` team-aware weekly retrospective [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- GBrain persistent-memory integration: `/setup-gbrain` onboards in four paths (PGLite local / Supabase existing URL / Supabase auto-provision via Management API / remote gbrain MCP over Tailscale-ngrok-LAN), registers `gbrain serve` as MCP typed tools, and assigns each repo a sticky per-remote trust tier — read-write / read-only / deny [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Memory hygiene: `/learn` reviews/searches/prunes/exported cross-session learnings (patterns, pitfalls, preferences); `$B domain-skill save` parks per-site notes in quarantine until 3 successful uses before activation, with optional cross-project promotion [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Deny-default browser escape hatch: raw CDP calls require explicit addition to `browse/src/cdp-allowlist.ts` with a one-line justification; output of data-exfiltration-capable methods wrapped in an UNTRUSTED envelope [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Prompt-injection defense stack: datamarking, hidden-element stripping, ARIA scrubbing, URL blocklist, plus a ~22MB ML classifier running locally in a sidecar subprocess whose verdict combiner requires classifier agreement before blocking; all on-machine, zero network calls; emergency kill switch `GSTACK_SECURITY_OFF=1` [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Egress receipt auditor (`gstack-egress`): every off-machine send first writes a tamper-evident, hash-chained receipt to `~/.gstack/security/egress.jsonl`; `list`/`grants`/`verify` subcommands, exit 3 on chain tamper; sensitive sinks refuse to send if the receipt can't be written; telemetry opt-in and default-off under the same regime [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Token bill-of-materials (`gstack-context-bill`): offline audit of what an installed skills tree costs per session (always-on frontmatter vs per-invocation SKILL.md + forced references), `--diff`, `--budget` ceiling enforcement, `--exact` mode requires an egress receipt before sending text to Anthropic's count_tokens [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Verification gating: opt-in `gstack-verify-gate` Stop hook blocks turn-end until the declared verify command passes (trust granted once per repo, audit-logged, invalidated by command edits); `gstack-wtree` content fingerprint + `gstack-evidence` ledger grade test evidence FRESH/STALE/MISSING so `/ship` cites fresh proof instead of re-running suites; `gstack-issue-guard` wraps fetched GitHub issue/PR text in a labeled injection-defense envelope enforced by CI scanner [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Safety guardrails on demand: `/careful` warns on destructive commands with hard-denied root/home recursive deletes and default-branch force-pushes; `/freeze` restricts edits to one directory; `/guard` = both; `/investigate` auto-freezes to the module under investigation [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]
- Multi-host installer: one setup targeting 10 coding agents (`--host codex/opencode/cursor/factory/slate/kiro/hermes/gbrain…`), model-aware behavioral profiles for Codex; OpenClaw integration via ACP session spawning plus four native ClawHub methodology skills [VERIFIED-fetched:https://raw.githubusercontent.com/garrytan/gstack/main/README.md]

## Notable absences
No department concept — a flat skill namespace (optional prefix) rather than scoped packs; no non-technical onboarding path (assumes Claude Code fluency). macOS/Bun-centric install (Node fallback on Windows only); iOS QA requires a Mac host. Parallel-sprint story leans on external Conductor SaaS. No evaluation harness for skill quality (no elevenlabs-style trigger evals). Telemetry exists even if default-off — under LastHarness it would be denied outright rather than receipted.

## Feature inventory
- **Terminal-native coding assistant, OpenCode fork**: keeps OpenCode's multi-provider/TUI/LSP/MCP/plugins core and adds persistent memory, context management, subagent orchestration, goal-driven loops, compose workflows, self-improvement [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **Trajectory substrate**: runtime data lives under XDG dirs — SQLite database, memory, logs in `~/.local/share/mimocode/`; session traces are the durable record `/dream` and `/distill` operate on [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **`/dream` — trace mining into memory**: "scans recent session traces, extracts persistent knowledge into project memory, and removes outdated entries" — the trajectory→proposal step: mined knowledge lands as candidate MEMORY.md content [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **`/distill` — trace mining into skills**: "discovers repeated manual workflows in recent work and packages high-confidence candidates into reusable skills, subagents, or commands" — repeated-across-runs is the implicit success filter (only workflows that worked get repeated) [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **Outcome-bearing record format that IS explicit — `research-experiment` workflow**: Baseline → Loop → Audit → Report over "a mechanically verifiable metric": each loop iteration runs hypothesize → implement → evaluate with keep/revert decisions, "audits for metric gaming", and produces "a reproducible result log" under a fixed evaluation command and explicit editable-file scope — i.e., trajectories tagged by a machine-checkable outcome plus an anti-gaming audit pass [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **Judge-gated stop conditions**: `/goal` sets a stopping condition; when the agent tries to stop, "an independent judge model evaluates the conversation to decide whether the condition is truly satisfied — preventing premature 'optimistic stops'" [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **Persistent memory files + budgeted injection**: `MEMORY.md` project memory, `checkpoint.md` maintained by a checkpoint-writer subagent, `notes.md`, `tasks/<id>/progress.md`; SQLite FTS5 full-text search; auto-injection on resume governed by token budget with importance ranking; context reconstruction rebuilds from checkpoint+memory+task-progress+recent messages near the window limit; `/context-limit` forces earlier compaction per model [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **`evolve` skill — total self-modification**: "rewrite any layer of the agent: tools, behavior hooks, knowledge, workflows, even the UI" [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **Permission model**: out-of-project paths trigger `external_directory` prompts (with a documented, risk-flagged allowlist escape hatch); `--dangerously-skip-permissions` injects an allow-all base BENEATH user rules so explicit deny still wins [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]
- **Workflows are deterministic JS in a sandboxed runtime** (compose / deep-research / fact-check / research-experiment built-in), custom ones dropped in `.mimocode/workflows/`; three-agent surface (build/plan/compose) with mode-locking after first message for tool-call reliability [VERIFIED-fetched:https://raw.githubusercontent.com/XiaomiMiMo/MiMo-Code/main/README.md]

## Notable absences
No published trajectory record schema (field names, tag taxonomy, retention) — mining endpoints are documented, the wire format is code-level, not README-level; the registry phrase "outcome-tagged" is therefore carried at design-note strength, anchored by research-experiment's explicit result log rather than a general trace format. No cross-session learning beyond memory/skills (no population/generational search). Voice input routes to Xiaomi-hosted ASR by default (third-party audio egress unless re-pointed to a self-hosted relay, which the README does support). Fork lineage means OpenCode-core behaviors were dispositioned in #—the opencode dossier; this entry claims only the delta.

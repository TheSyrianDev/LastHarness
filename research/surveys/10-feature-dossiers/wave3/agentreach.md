## Feature inventory (what tenlifejosh/agentreach actually is)
- **Persistent authenticated web access for AI agents**: "Harvest a session once — automate forever"; a Python 3.10+ CLI (`pip install agentreach` + Playwright Chromium) letting agents act on consumer platforms (KDP, Etsy, Gumroad, Pinterest, Reddit, X, Nextdoor) headlessly after one human login [VERIFIED-fetched:https://raw.githubusercontent.com/tenlifejosh/agentreach/main/README.md]
- **Encrypted session vault**: per-platform `.vault` files in `~/.agentreach/vault/`; Fernet (AES-128-CBC + HMAC-SHA256) with PBKDF2-HMAC-SHA256 key derivation (480,000 iterations) seeded from the machine's MAC address — deliberately non-portable ("a vault file moved to another machine cannot be decrypted"); stores Playwright cookies, OAuth tokens, API keys, harvest metadata; "What leaves disk: Nothing … no network calls except to the target platform" [VERIFIED-fetched:https://raw.githubusercontent.com/tenlifejosh/agentreach/main/README.md]
- **Two auth models**: browser-session harvesting for KDP/Pinterest/Reddit/X/Nextdoor (visible login once → cookies auto-captured via URL-pattern detection → replayed in headless Playwright) and API-token storage for Etsy/Gumroad (OAuth/API keys set once via CLI) [VERIFIED-fetched:https://raw.githubusercontent.com/tenlifejosh/agentreach/main/README.md]
- **Platform driver matrix**: KDP paperback upload/draft-resume/bookshelf (stable); Etsy listing creation/images/digital files (stable); Gumroad publish/sales/list (stable); Pinterest pin/board (stable); Reddit post/comment (beta); X tweet/reply (beta); Nextdoor post (beta); TikTok vault-only [VERIFIED-fetched:https://raw.githubusercontent.com/tenlifejosh/agentreach/main/README.md]
- **Fragility admitted in-source**: "Browser-based drivers are inherently fragile. Platform UI changes will break selectors. Selectors were last verified March 2026"; bot-detection warning that X/Reddit/KDP fingerprint headless browsers and may invalidate sessions "within hours to days"; `playwright-stealth` "not guaranteed"; roadmap v0.4 admits "currently silent swallows in some drivers" [VERIFIED-fetched:https://raw.githubusercontent.com/tenlifejosh/agentreach/main/README.md]
- **Ops commands**: `status` session-health tables with TTL expiry estimates, `doctor` diagnostics, `verify` live-request session check, machine-bound encrypted `backup`/`restore` [VERIFIED-fetched:https://raw.githubusercontent.com/tenlifejosh/agentreach/main/README.md]
- **Documented security limits**: MAC-based key derivation unrecoverable across hardware/VM changes; "No protection against local root access — if an attacker has root on your machine, they can read the MAC and reconstruct the key" [VERIFIED-fetched:https://raw.githubusercontent.com/tenlifejosh/agentreach/main/README.md]

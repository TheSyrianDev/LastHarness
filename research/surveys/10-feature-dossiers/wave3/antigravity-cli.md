## Feature inventory
- **Terminal surface of the Antigravity agent harness**: "brings the core capabilities of Antigravity 2.0 (multi-step reasoning, multi-file editing, tool calling, and persistent history) directly to your terminal"; TUI optimized for keyboard-driven workflows and remote SSH sessions with minimal resource overhead; launched via `agy` [VERIFIED-fetched:https://raw.githubusercontent.com/google-antigravity/antigravity-cli/main/README.md]
- **Multi-surface composition**: CLI and Antigravity 2.0 GUI run on a "Shared Core Agent Engine"; preferences and permissions "sync bidirectionally" between surfaces; terminal sessions can be exported to the GUI to continue working [VERIFIED-fetched:https://raw.githubusercontent.com/google-antigravity/antigravity-cli/main/README.md]
- **Keyring-first auth with SSH-aware flow**: authenticates via the system keyring; on SSH sessions detects the remote context and prints an authorization URL to complete Google Sign-In locally; `/logout` clears credentials; enterprise path binds a GCP project at onboarding [VERIFIED-fetched:https://raw.githubusercontent.com/google-antigravity/antigravity-cli/main/README.md]
- **Default-on telemetry with opt-out**: "By using Antigravity CLI, you agree to help improve the product by allowing Google to collect and use your Interactions data… You can choose to opt out at any time via your settings"; ToS warning block lists autonomous code execution, data exfiltration, prompt injection, supply-chain risks and tells users to "monitor and verify all actions taken by the agent" [VERIFIED-fetched:https://raw.githubusercontent.com/google-antigravity/antigravity-cli/main/README.md]
- Official docs live outside the repo at antigravity.google/docs/cli/overview; repository itself carries no license, no docs beyond the README, no source-language metadata in the API response (distribution appears binary-first) [REPORTED-unverified:repo structure per GitHub API metadata]

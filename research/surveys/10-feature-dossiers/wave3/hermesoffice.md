# HermesOffice — Feature Dossier
Registry: #75 | Category: 07 | Verified: 520 stars, Apache-2.0 (with `ee/` enterprise-license exception), pushed 2026-08-13 (GitHub API 2026-08-24)

Note-tier dossier. Recorded disposition: agent-native document formats rendered losslessly → §14.5 Document Store / §17 fast-follow. The format model in detail — **canonical file + narrow anchored patches, never regeneration**: on open, the original `.docx` is archived by hash and never touched; `docx-engine` parses only top-level `word/document.xml` elements (`w:p`, `w:tbl`, …) into a block tree where each block carries a stable `docxIndex` anchor plus its original XML slice; edits (human or agent) dirty only touched blocks; on save, dirty blocks are re-emitted as OOXML fragments that reference existing styles only, spliced back into the original XML, and the zip is repacked copying every untouched entry byte-for-byte. Result: opening and saving "never breaks layout" in Word/Excel/PowerPoint — lossless round-trip with agents writing through the same narrow-patch path as humans.

- docx round-trip architecture: archive-original-by-hash → parse top-level elements → block tree anchored by `docxIndex` + original XML slice → save splices dirty-block OOXML fragments (existing styles only) into original XML → repack zip byte-for-byte for untouched entries [VERIFIED-fetched:https://raw.githubusercontent.com/criptogus/HermesOffice/main/README.md]
- Same narrow-patch philosophy across formats: original file is source of truth everywhere [VERIFIED-fetched:https://raw.githubusercontent.com/criptogus/HermesOffice/main/README.md]
- Sheets: open-source Univer core + in-house Rust sidecar (calamine + IronCalc) for `.xlsx` import/export; charts, pivot tables, slicers, conditional formatting, formula tracing [VERIFIED-fetched:https://raw.githubusercontent.com/criptogus/HermesOffice/main/README.md]

## Notable absences
No collaboration/multi-user story yet (single-operator local-first). The MCP server and unified Proposed Change pipeline are roadmap P0 — the strongest LastHarness-relevant pieces are not shipped as of this revision (v0.7.0). No CLI/headless batch mode documented; engines exist but no documented server-side usage. Reserved closed-license `ee/` directory signals future feature split to watch. No retention/versioning policy beyond per-edit snapshots, no encryption-at-rest story, and no department-scoped access concept — all left to the integrating system.

## Feature inventory
- **Two products in one repo**: (1) the original terse-output *skill* (MIT, installs into 30+ agents via `npx skills add`) and (2) *Caveman Proxy*, an input-compression local proxy wrapping the agent CLI (`npm i -g @caveman-ai/cli && caveman claude`), where "the Engine-linked runtime is BSL-1.1 source-available" while CLI/skill stay MIT [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]
- **Skill scope is OUTPUT-only — author's own warning**: "The skill only shrinks **output** tokens. Input and reasoning tokens are untouched, and the skill itself adds ~1–1.5k input tokens per turn. Whole-session savings run smaller than the output number, and on already-terse workloads they can go net-negative." [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]
- **Skill benchmark**: average reply 1,214 → 294 tokens (−65%) across 10 tasks; modes `/caveman lite|full|ultra|wenyan-lite|wenyan-full|wenyan-ultra|off`; companion commands `/caveman-commit`, `/caveman-review`, `/caveman-compress`, `/caveman-stats` plus cavecrew subagent presets [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]
- **Proxy input compression**: pinned 54-run Claude Code wrap benchmark reports 33.2% fewer provider-reported input tokens while passing all 18 exact-answer checks (`benchmark_counterfactual`, explicitly "neither is a provider invoice") [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]
- **Engine payload routing**: `detect()` types each payload then routes — json keeps keys/error subtrees (70–90%), log keeps errors/stack traces (85–95%), code keeps imports/signatures with valid syntax (40–70%), diff, search-result, text/HTML each with stated keep-rules; `contextwindow.Pack()` fits context to a token budget by BM25 relevance + recency + error signal, returned in original order [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]
- **Byte-exact recovery (CCR)**: proxy keeps recovery copies on your disk; "CCR stays in a SQLite file on your disk"; MCP toolkit exposes `caveman_retrieve` alongside `caveman_compress`/`caveman_stats`/TOON encode-decode; `caveman mem recover <handle>` returns original bytes [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]
- **Verb set around the engine**: `caveman learn` (read-only scan of real agent history → Cave Score + ranked token sinks), `learn implement` (consent-gated diffs applied by your own agent, revert if tokens/turn don't drop), `shrink -- <cmd>`, `browse` (local Chrome over compressed a11y tree), `trial` A/B, pixel-mode skill conversion [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]
- **Pixel mode (skills-as-images)**: `caveman convert` renders installed `SKILL.md` bodies to PNG pages (frontmatter stays text); measured −61% est. tokens on the caveman skill itself; `--revert` restores byte-identical from `SKILL.orig.md`; converts only when pages beat text [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]
- **Pairing with Ponytail is explicit in both repos**: ponytail's README states the division of labor — caveman shrinks what the agent says, ponytail what it builds [VERIFIED-fetched:https://raw.githubusercontent.com/DietrichGebert/ponytail/main/README.md]
- **Privacy posture**: local compression needs no account; CLI sends anonymous usage stats (commands + token counts) BY DEFAULT, opt-out via `caveman telemetry off` or `DO_NOT_TRACK=1`; "Caveman Cloud" (signed receipts, `verified` grade evidence) is a waitlisted hosted service [VERIFIED-fetched:https://raw.githubusercontent.com/JuliusBrussee/caveman/main/README.md]

## Notable absences
No enforcement: the skill cannot block verbose output, only request it — compliance is probabilistic and the README admits session-level savings may go net-negative. The proxy half drags a second language runtime (Go) under a BSL-1.1 source-available license (auto-converting to Apache-2.0 only on 2030-06-21 or four years per version) — not OSI open source today and a standing process besides. Nothing here touches memory, egress, onboarding, or decision logging. Benchmarks are self-run and pinned ("inferred"/"benchmark_counterfactual", never provider invoices). Wenyan modes and cavecrew presets are culture-specific extras with no LastHarness analog.

## Notable absences
No verification gate in the learning loop at any point in the primary source — skill creation and improvement are agent-judged, so the §10.2 note remains a structural borrowing, not an implementation match. No audit log, decision record, or tamper-evident history is mentioned; memory and session search are the only durable surfaces. No allow-list granularity described at README level beyond migration of "command allowlist" patterns from OpenClaw. The messaging half is inseparable from the product's identity (it headlines the feature table), reinforcing that this entry stays skip-tier wholesale: the only portable atoms (bounded reflection shape, trajectory-export idea) were already carried by §10.2 and now §12.4.

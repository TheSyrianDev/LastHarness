## Compliant re-implementation sketch
- Keep the product thesis — watchable office of coordinated workers with governance rails — rebuilt entirely on kernel primitives; nothing stands between dispatches.
- Manager: Michael's adjudication becomes the §4.6 kernel manager — decompose, route task-scoped, escalate only spend/destructive/scope items to the approvals queue; routine resolution stays autonomous.
- Coordination: delete outbox/inbox mailboxes. Workers receive instructions at spawn and return results via the dispatch Output contract (§16.6); anything another worker must see is written to the §12 decision log and surfaced by query, not message.
- Memory: hive/MemPalace collapses into the Information dept's gated store (§6.2/§6.3) — condensation job, semantic recall behind bounded retrieval, Knowledge Graph as curated dept pages; no agent reads the whole hive.
- Governance: adopt the steer→constrain→stop ladder as the named escalation inside §10.2's capped loops, and per-agent budget enforcement under cost routing (§14.4).
- Telemetry: transcript-derived real cost + OTel spans land directly in the §16.6 Output 3 schema (the adopted LangFuse shape); tool waterfall renders from those spans.
- Owner console: floor avatars + IDE git rails merge into the R7 owner-console candidate — read-only visualization of live worktrees, traces, and approvals; fs/git always brokered through kernel handles.
- Stay out: node-pty wrapping of vendor CLIs (wrapped-CLI exclusion), Electron standing shell, persistent mailboxes, Slack-triggered spawns until the §16.4 messenger clause reopens.

## Notable absences
No egress gateway — provider keys and Slack webhooks go straight out; no allow-listing of network destinations anywhere. No department scoping: the hive memory and blackboard are shared by every agent by design. No immutable/tamper-evident audit trail distinct from the event log. No verification-suite gating (CI watcher ingests results; nothing blocks on them). Setup assumes developer tooling (Node 18+, C++ toolchain for node-pty) — no non-technical onboarding path. Telemetry opt-out exists, but official builds phone home anonymous usage events by default.

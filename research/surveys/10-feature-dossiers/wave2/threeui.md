# ThreeUI Community (MengTo/threeui) — Feature Dossier
Registry: #125 | Category: 05 | Verified: 3,221 stars, MIT, last push 2026-08-23

## Feature inventory
- **Login-free Community edition sharing the full application shell with the main product**: same layout, navigation, browse grid, search, themes, responsive behavior, component pages, live renderers, controls, variant picker, and source tabs; the catalog is the only product-level difference (Pro and Beta components removed; every Community component keeps all free variants and controls) [VERIFIED-fetched:https://raw.githubusercontent.com/MengTo/threeui/main/README.md]
- **Catalog contents**: 50 Community parent components, 111 Community routes, 141 free variant records plus 23 singleton components (164 browse results); complete implementation source and required assets included [VERIFIED-fetched:https://raw.githubusercontent.com/MengTo/threeui/main/README.md]
- **npm component library `@designcodeio/threeui`**: root import or component-subpath import "for the smallest development import graph"; components rendering full HTML documents expect runtime files at root-relative URLs (copyable from `lib-dist/assets/` or overridable via `sourceUrl`/`assetBaseUrl` props) [VERIFIED-fetched:https://raw.githubusercontent.com/MengTo/threeui/main/README.md]
- **Pro source access via entitled CLI, deliberately not npm**: `npx @designcodeio/threeui-cli add <component>`; OAuth with PKCE, refreshable session stored owner-only, account entitlement checked on EVERY server request, refuses to overwrite changed project files unless `--force` is supplied [VERIFIED-fetched:https://raw.githubusercontent.com/MengTo/threeui/main/README.md]
- **Fail-closed community sync pipeline**: `npm run sync:community` fails closed, filters Pro/Beta BEFORE generating the public import graph, preserves all free metadata/options, removes restricted font assets; writes `public/community-sync-report.json` (counts + per-component variant/control parity), `public/source-code.json` (Code-tab bundles), `src/data/shaders.tsx` [VERIFIED-fetched:https://raw.githubusercontent.com/MengTo/threeui/main/README.md]
- **Release automation**: private repo re-syncs after every push to main; no-op sync exits without a release; changes land on an `automation/community-sync` branch as one reviewed PR; semver inferred from change class (additions→minor, removals→major, compatible changes→patch); publishes via npm trusted publishing with provenance after a clean build, boundary audit, package creation, and anonymous installation smoke test [VERIFIED-fetched:https://raw.githubusercontent.com/MengTo/threeui/main/README.md]
- **Registry-reported**: procedural Three.js components "copyable as agent prompts" and MCP + skills shipping in the Pro tier [REPORTED-unverified — absent from README and fetched docs; the public source documents only the CLI bundle flow and `source-code.json` data bundles]
- **License split**: application code, Community component code, and authored imagery MIT; bundled fonts SIL OFL 1.1; Three.js runtime files MIT; remote catalog thumbnails/previews loaded from threeui.com are NOT redistributed by the repo [VERIFIED-fetched:https://raw.githubusercontent.com/MengTo/threeui/main/README.md]

## Notable absences

No documentation site linked beyond the README itself. No changelog file described for public package content beyond semver inference from sync diffs. No design-tool (Figma et al.) bridge. No offline/bundled thumbnails — previews depend on the live threeui.com origin.

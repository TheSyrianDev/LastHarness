## Feature inventory
- **SEO Agent Skill with one-line install into Agent-Skills-compatible clients** (Codex, Claude Code, Cursor): `npx skills add joeseesun/qiaomu-seo` with `--list` discovery check; scope covers technical SEO audit, keyword–page strategy, organic-traffic diagnosis, site migration, code fixes, and effect verification [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]
- **Works the real retrieval chain instead of metric-scoring**: "not a scorer of title character counts, H1 counts, and keyword density" — pipeline is crawler access & URL discovery → fetch & JavaScript rendering → indexability → canonical/hreflang → page relevance & search intent → internal linking & information architecture → search-performance measurement [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]
- **Input→deliverable contracts per task family**: URL/code/rendered pages/sitemaps → issue lists ranked by impact × confidence × effort × dependencies; Search Console/Bing WMT/analytics/logs → segmented traffic/index diagnostics with candidate causes, missing-evidence flags, and next verification steps; product/keyword data → keyword-to-page maps, content briefs, create/merge/improve page recommendations avoiding keyword cannibalization; migration plans → URL inventories, redirect maps, canonical/hreflang/sitemap consistency checks, launch monitoring, rollback boundaries; authorized code → minimal fixes with change records, test results, rollback info, review timepoints [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]
- **Evidence grading**: every conclusion labeled direct observation / reasonable inference / missing evidence; impact and confidence expressed separately; fabrication refused outright — no invented search volume, keyword difficulty, rankings, traffic, or competitor data; no promises of rankings, indexing, rich results, or AI citations [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]
- **Stale-source registry (v1.2)**: 33 official sources registered (Google, Bing, IndexNow, Schema.org, web.dev, OpenAI, Microsoft, Perplexity) each recorded with source, review date, and feature lifecycle, with known-stale assertions automatically blocked; materialized as `data/seo-source-registry.json`, enforced by `validate_knowledge.py --strict-stale` [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]
- **Layer-separation discipline**: Schema.org syntax validity ≠ Google feature eligibility ≠ actual rich-result display; IndexNow receipt ≠ crawl ≠ indexation; Lighthouse lab data diagnoses while Core Web Vitals field data describes real-user distributions and neither substitutes for the other; robots.txt governs crawling, robots meta/X-Robots-Tag indexing/display, canonical is a preference signal, sitemap/IndexNow are discovery channels — none guarantee inclusion [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]
- **Read-only-by-default authority boundaries**: audit/diagnose/compare modes never modify code, index controls, webmaster platforms, or live data; fix/implement executes ONLY on explicit authorization and preserves pre-change evidence, test results, rollback info, and a monitoring window [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]
- **Validation harness**: `validate_skill.py` (structure), `validate_knowledge.py --strict-stale`, `validate_audit.py path/to/audit.json`, skill-IR export script, trigger-eval case runner (`evals/trigger_cases.json`) [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]
- **Graceful unknown-handling**: without Search Console or keyword tools it switches to qualitative research and marks volume/KD/coverage `unknown` rather than estimating; `site:` queries explicitly rejected as full-index reports in favor of Search Console URL Inspection [VERIFIED-fetched:https://raw.githubusercontent.com/joeseesun/qiaomu-seo/main/README.md]

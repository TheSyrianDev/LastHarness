## Feature inventory
- **Terminal-as-console for parallel agent sessions**: Ghostty-based (libghostty embedded "the way apps use WebKit"), vertical-tab sidebar per workspace showing **git branch, linked PR status/number, working directory, listening ports, and latest notification text**; horizontal/vertical splits [VERIFIED-fetched:https://raw.githubusercontent.com/manaflow-ai/cmux/main/README.md]
- **Attention-routing notification system**: panes get blue rings and tabs light up when agents need attention; OSC 9/99/777 escape-sequence pickup plus `cmux notify` CLI wired into agent hooks (Claude Code/OpenCode/etc.); aggregated notification panel; ⌘⇧U jump-to-latest-unread; unread-state toggles [VERIFIED-fetched:https://raw.githubusercontent.com/manaflow-ai/cmux/main/README.md]
- **Subagents become visible panes**: "When an agent spawns subagents or teammates, cmux turns them into native panes and splits instead of hidden background processes"; supports Claude Code teams and oh-my-opencode multi-model orchestration so "every agent in a run is visible and controllable" [VERIFIED-fetched:https://raw.githubusercontent.com/manaflow-ai/cmux/main/README.md]
- **Scriptable in-app browser pane**: API ported from vercel-labs/agent-browser — accessibility-tree snapshots, element refs, click/fill/evaluate JS, console/network reading; agents verify their own web changes in a split next to the terminal; browser import of cookies/history/sessions from 20+ browsers; SSH workspaces route browser through remote network so localhost works [VERIFIED-fetched:https://raw.githubusercontent.com/manaflow-ai/cmux/main/README.md]
- **Session restore with trust-gated resume commands**: versioned snapshot under `~/Library/Application Support/cmux` restores layout/dirs/scrollback/browser history; supported agent sessions resume when hooks saved native session IDs (`~/.cmuxterm/` mappings); custom resume bindings are stored for inspection and only auto-run when user-approved signed command prefixes exist — "Approved prefixes are also bound to the working directory and exact environment values"; "**Sensitive environment keys such as tokens, passwords, secrets, and API keys are dropped before a resume binding is stored**"; opt-out flag for auto-resume [VERIFIED-fetched:https://raw.githubusercontent.com/manaflow-ai/cmux/main/README.md]
- **Full CLI + Unix socket automation surface**: create workspaces/tabs, split panes, send keystrokes, read screen contents, screenshots, drive browser — everything the GUI does [VERIFIED-fetched:https://raw.githubusercontent.com/manaflow-ai/cmux/main/README.md]
- **Skills collection for agents driving cmux**: reusable workflows (CLI control, workspace automation, settings, browser surfaces) in a companion repo [REPORTED-unverified — linked repo not fetched]
- **Commercialization envelope**: free/open-source core; Founders Edition sells early access to cmux AI context features, iOS companion beta, Cloud VMs, voice mode [VERIFIED-fetched:https://raw.githubusercontent.com/manaflow-ai/cmux/main/README.md]

## Notable absences
No permission model for what agents may do through the socket API beyond physical local access (single-user assumption throughout). No audit trail of agent-initiated browser/keystroke actions. No Linux build despite libghostty being cross-platform — a deliberate platform bet, not a technical limit. License detection mismatch (API NOASSERTION vs README GPL-3.0-or-later) remains the standing flag from registration. As predicted by the ledger, the value here is entirely render-side: cmux demonstrates owner demand for per-agent visibility rows and attention triage without adding anything that executes on LastHarness's behalf.

## Feature inventory
- **Personal AI assistant, Agent OS architecture (v2.0 rewrite)**: per-agent workspace with three pillars — Resources ("transparent on disk"), Governance ("allow/deny/ask/sandbox"), Sandbox (macOS/Linux/Windows); protocol-neutral MCP/A2A/ACP connector layer with encrypted credentials and per-call policy gate [VERIFIED-fetched:https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md]
- **Five security layers**: kernel-level Sandbox (Seatbelt/Bubblewrap+Landlock/AppContainer per OS); Tool Guard YAML rule engine with `ShellEvasionGuardian` inspecting every tool call pre-execution for command injection, path traversal, reverse shells, obfuscation, with STRICT/SMART/AUTO/OFF approval levels; File Guard default-protecting `~/.qwenpaw.secret/`, `~/.ssh`; Skill Scanner pre-activation scanning (block/warn/off + whitelist) detecting prompt injection, hardcoded secrets, data exfiltration; Access Policy declarative allow/deny/human-approval rules per capability call with tool-level granularity and source-aware matching [VERIFIED-fetched:https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md]
- **Three-layer memory**: live working context, full verbatim history, self-evolving personal knowledge base via ReMe — "conversations and resources continuously become readable, editable, searchable, and linked Markdown memory"; Scroll Context: every turn persisted, evicted turns indexed with on-demand recall, "nothing summarized away" [VERIFIED-fetched:https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md]
- **Multi-channel reach**: DingTalk, Lark, WeChat, Discord, Telegram, iMessage, QQ — "one instance, all channels"; console/TUI/desktop app alongside; multi-channel broadcasting automation listed as a headline use case [VERIFIED-fetched:https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md]
- **Scheduling & automation**: cron/scheduled tasks docs surface, Heartbeat scheduled check-in/digest, recurring news digests/report generation/multi-channel broadcasting [VERIFIED-fetched:https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md]
- **Local-first model story**: QwenPaw-Flash purpose-trained 2B/4B/9B agent models (Q4/Q8); built-in llama.cpp runtime with hardware-aware download recommendations; Ollama/LM Studio interop; "no API key, no cloud dependency" path [VERIFIED-fetched:https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md]
- **Deployment spread includes cloud**: Docker, Alibaba Cloud ECS one-click, AgentScope Platform free 7/24 cloud hosting, ModelScope Studio — plus local pip/script/desktop [VERIFIED-fetched:https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md]
- **Telemetry**: anonymous once-per-version at `qwenpaw init` — version/install-method/OS/Python/CPU/GPU; accepted AUTOMATICALLY under `--defaults`, opt-out requires interactive decline [VERIFIED-fetched:https://raw.githubusercontent.com/agentscope-ai/QwenPaw/main/README.md]

## Notable absences

Approval levels include OFF and AUTO — convenience escape hatches LastHarness doesn't offer. Channel credentials management details live in unfetched hosted docs (thin-source limitation acknowledged). Nothing found that upgrades an adopted design; the value of this entry is competitive confirmation plus four borrowable rule/heuristic shapes.

## Feature inventory
- **Meta-harness positioning**: "Agent = Model + Harness … Ruflo is the harness — the execution layer around Claude Code and Codex that adds 100+ specialized agents, coordinated swarms, self-learning memory, federated comms across machines"; one init writes `.claude/`, `.claude-flow/`, hooks, MCP server into the workspace; hooks "automatically route tasks … and coordinate agents in the background" [VERIFIED-fetched:https://raw.githubusercontent.com/ruvnet/ruflo/main/README.md]
- **Standing swarm machinery**: hierarchical/mesh/adaptive topologies; Queen-led hierarchy with Raft/Byzantine/Gossip consensus; 12 auto-triggered background workers (audit, optimize, testgaps…); 27 orchestration hooks; 98 agents / 60+ commands / 30 skills on full install [VERIFIED-fetched:https://raw.githubusercontent.com/ruvnet/ruflo/main/README.md]
- **Agent federation ("Slack for Agents")**: zero-trust cross-machine collaboration — identity via mTLS + ed25519 challenge-response ("No API keys, no shared secrets"); 14-type PII detection pipeline on every outbound message with per-trust-level policies BLOCK/REDACT/HASH/PASS; **behavioral trust scoring formula `0.4×success + 0.2×uptime + 0.2×threat + 0.2×integrity`** with instant downgrade on misbehavior and history-gated upgrades; untrusted peers "see discovery info, not your memory"; compliance modes emitting HIPAA/SOC2/GDPR audit trails; optional WireGuard mesh layer tying packet reachability to federation trust [VERIFIED-fetched:https://raw.githubusercontent.com/ruvnet/ruflo/main/README.md]
- **GOAP A* goal planner**: plain-English goals → extracted success criteria/preconditions → A* search through action state space → dispatched tool calls; adaptive replanning re-runs A* from current state on failure instead of restarting; visual plan tree showing "exactly why an agent picked a path"; live agent dashboard with role/memory-namespace/token-budget/status per agent and kill-switch for runaway workers [VERIFIED-fetched:https://raw.githubusercontent.com/ruvnet/ruflo/main/README.md]
- **Vector memory**: HNSW-indexed AgentDB — "measured ~1.9x faster at N=20k, ~3.2x–4.7x at N=5k vs brute force (recall@10 ~0.99); ANN wins above the crossover, ties/loses at small N", audit report + benchmark script linked inline (honest crossover disclosure) [VERIFIED-fetched:https://raw.githubusercontent.com/ruvnet/ruflo/main/README.md]
- **Self-learning claims**: SONA neural patterns, ReasoningBank, trajectory learning; task-routing accuracy quoted at 89% [REPORTED-unverified — no methodology in README]
- **MetaHarness audit plugin**: grade agent-setup readiness 1–100, scan tool configs for security risks, project snapshots to catch regressions over time, template matching; `ruflo eject` converts a ruflo project into a standalone toolkit [VERIFIED-fetched:https://raw.githubusercontent.com/ruvnet/ruflo/main/README.md]
- **Supply-chain verification**: `ruflo verify` cryptographically proves installed bytes match a signed witness manifest; Team Gateway Checklist mandates before-merge gates, dual-mode handoff, memory namespace sharing, witness entry per merge [VERIFIED-fetched:https://raw.githubusercontent.com/ruvnet/ruflo/main/README.md]
- **Cost tracker**: token usage budgets + alerts per provider; multi-provider routing w/ failover across Claude/GPT/Gemini/Cohere/Ollama [VERIFIED-fetched:https://raw.githubusercontent.com/ruvnet/ruflo/main/README.md]

## Per-feature verdict
| Feature | Type | LastHarness landing | Rationale |
|---|---|---|---|
| Standing swarms: queen processes, always-on background workers, hook-driven background coordination | ❌ Conflict-skip CONFIRMED | §16.5 ephemeral workers only; §4.4 all coordination kernel-mediated | Ledger verified: resident coordinators and auto-triggered workers are standing processes, and agent-to-agent task routing through a queen bypasses kernel mediation by construction. LastHarness's equivalent is the kernel dispatching ephemeral workers — no peer mesh, no queen. |
| Cross-machine federation of live agents | ❌ Conflict-skip | ONE self-hosted Linux-env boundary §16.1 | Even with excellent zero-trust engineering, federating executing agents across machines violates the single-boundary invariant. The *protocol patterns* below are what survive. |
| Behavioral trust scoring (`0.4·success + 0.2·uptime + 0.2·threat + 0.2·integrity`, instant downgrade) | 🧩 Design note | Verifier dept — worker reputation within the decision log | The one genuinely portable governance mechanism: score workers from logged outcomes, gate future dispatch breadth on the score, demote instantly on integrity failures, require history for promotion. Computable entirely from LastHarness's immutable SQLite decision log — no new infrastructure. |
| PII outbound pipeline with per-trust-tier actions (BLOCK/REDACT/HASH/PASS) | 🧩 Design note | §7.1 egress gateway content policy | Four-valued content handling beats binary allow/deny for the egress gateway's future policy engine: match class → action tier. Adopt the vocabulary even though LastHarness's default-deny keeps PASS rare. |
| GOAP planner: preconditions/effects, replan-from-current-state, explainable plan tree | 🧩 Design note | Kernel planning layer design pressure (§16.6 dispatch composition) | Replanning from current world-state instead of restart, plus a plan tree that shows WHY each step was chosen, are the right shapes if LastHarness ever adds automated multi-step decomposition. Stays a note: planning quality needs a deterministic evaluator to be safe. |
| `ruflo verify` signed-witness byte verification + per-merge witness entries | ⚙ Feature adoption (pattern) | Skills supply chain & deployment integrity §14.5 | Signed manifests proving installed bytes = reviewed bytes is cheap, compatible, and closes the install-time tamper window. Adopt as an ops procedure around model packs/skills, not as ruflo code. |
| MetaHarness readiness grading + tool-config security scan | 🧩 Design note | Self-audit pass over allow-lists/configs | A periodic local audit that grades config posture and diffs snapshots catches config drift — implementable as a scheduled Automation-dept re-check rendering into the notification queue (sanctioned recurrence), not a standing worker. |
| HNSW AgentDB w/ published crossover honesty | 🧩 Evidence note | Any future vector index choice | Rare candor: ANN loses below N≈5k. For LastHarness-scale stores, brute-force scan over SQLite may simply win; measure before adopting any ANN dependency. |
| Hosted UIs (flo.ruv.io, goal.ruv.io w/ Supabase) | ❌ Conflict-skip | Default-deny egress; cloud execution exclusion | Hosted control planes put coordination state in third-party cloud; excluded wholesale. |

## Notable absences
No verifier gate between swarm-agent output and acceptance beyond consensus choreography — quality control is topological, not outcome-validated (contrast loopx's validated-writeback). No immutable audit log: compliance trails exist only inside the federation product surface. Trust scoring inputs are self-reported counters, tamper-resistance unstated. Routing-accuracy (89%) and learning claims carry no methodology. The conflict ruling stands with high confidence; the extraction list above captures everything worth keeping.

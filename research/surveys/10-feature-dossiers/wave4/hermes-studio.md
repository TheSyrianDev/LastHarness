- **Three-tier architecture where the browser never executes**: Browser → BFF (Koa :8648) → Socket.IO `/chat-run` → Python agent-bridge broker → Hermes runtime; bridge broker on loopback IPC (`ipc:///tmp/hermes-agent-bridge.sock`) or Windows TCP 18765; frontend is presentation only [VERIFIED-fetched:https://raw.githubusercontent.com/EKKOLearnAI/hermes-studio/main/README.md]

## Notable absences
No verifier gate between workflow approval and execution beyond gate flags — budgets and deadlines exist but validation of outcomes is not described. No audit trail distinct from logs (log files ≠ tamper-evident decision record). No egress policy anywhere: voice/TTS/model adapters point at third-party clouds with no allow-list concept. Session search excludes read-only Hermes-history sessions (own DB only). BSL-1.1 means zero code reuse without license diligence despite "open-source" positioning in some badges — the adoption value is entirely pattern-level.

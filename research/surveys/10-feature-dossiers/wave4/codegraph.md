# CodeGraph — Feature Dossier
Registry: #139 | Category: 02 | Verified: 68,068★, MIT, pushed 2026-08-25

Adopt-tier dossier (ledger: "upgrades §6.3 code_index/repo-map family", 09-feature-extraction:257). Ticket directive: detail indexing/sync/retrieval mechanics. Rust-kernel code knowledge graph served to agents over MCP; 100% local (SQLite only, no API keys); this session's own AGENTS.md instructions are literally delivered by this product's MCP server.

## Feature inventory
- **Pre-indexed symbol/edge graph in per-project `.codegraph/codegraph.db` (SQLite + FTS5)**: tree-sitter grammars compiled into a native Rust kernel extract nodes (functions/classes/methods) and edges (calls/imports/extends/implements) for 20 languages; references resolved post-extraction (calls→definitions, imports→files, inheritance, framework patterns) [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Byte-identical graph guarantee**: each language ships in the Rust kernel only after "its graphs proved byte-for-byte identical to the reference engine on real repositories, from small libraries up to the Linux kernel"; platforms without a prebuilt binary or files with syntax errors fall back per-file to the portable engine — same graph either way [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Single-tool MCP surface**: one `codegraph_explore` tool returns relevant symbols' verbatim source + call paths between them (dynamic-dispatch hops included) + blast-radius summary; six other capable tools (`node/search/callers/callees/impact/files/status`) exist but are unlisted by default ("one strong tool steers agents better than a menu of narrower ones — fewer mis-picks"), re-enableable via `CODEGRAPH_MCP_TOOLS` env [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Three-layer auto-sync**: (1) native OS file watchers (FSEvents/inotify/ReadDirectoryChangesW) with debounced re-index (default 2000ms, tunable `CODEGRAPH_WATCH_DEBOUNCE_MS` clamped [100ms,60s], bursts collapse into one sync); (2) **per-file staleness banner** — during the debounce window, MCP responses referencing a pending file prepend a ⚠️ banner naming it and telling the agent to Read directly (validated: agent then says "Reading the file directly for the live content"); (3) connect-time catch-up reconciling `(size, mtime)` + content-hash on MCP reconnect so edits made while no server ran get absorbed [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Machine-adaptive pipeline sizing**: worker pools/resolver/caches sized from real core counts (container/cgroup-aware), honestly-measured available RAM, and measured per-project resolution cost. Data points: Swift compiler repo (27k files) fresh-index ~100s on workstation; Linux kernel (70k files, 2M symbols, 6.4M relationships) completes in <12 min on a 2-core/6GB VPS where RAM-first designs OOM; single-file edit re-syncs ~0.3–0.4s; measured 2–7× faster than fastest competitor's re-index-on-change across a 31-repo benchmark because cost grows with the *change*, not the repo [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Measured agent-level wins with contamination control**: median-of-4 headless Claude Code arms WITH vs WITHOUT the graph, CLI blocked via PreToolUse hook in BOTH arms (26 of 28 earlier control runs had reached CodeGraph through Bash when unblocked): 88% fewer tool calls, 53% faster, 62% fewer tokens, 44% cheaper, file reads cut to zero on all seven repos [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Honest negative result — residual context occupancy**: same measurement series reports CodeGraph sessions leave "~80% more retrieval context resident" at end of session (67k vs 18k tokens on VS Code): one dense verbatim payload stays in-window where grep-churn evicts. Explicit guidance: "If you run long sessions in a small window, budget for it" [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Framework-aware route edges**: routing files emit `route` nodes linked by `references` edges to handlers across 17 frameworks (Django urls.py, FastAPI decorators, Express/NestJS, Rails, Spring annotations, Axum, React Router/SvelteKit/Vue Router/Nuxt/Astro file-based routes…) so caller queries surface the URL pattern binding [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Cross-language bridging with provenance tags**: Swift↔ObjC auto-bridging rules, React Native legacy bridge/TurboModules/Fabric, native→JS event channels, Expo Modules — synthesized hops carry `provenance:'heuristic'` edges with `metadata.synthesizedBy:` channel name (e.g. `swift-objc-bridge`, `rn-event-channel`) so consumers can see how a hop got into the graph; validated against small/medium/large real repos per bridge [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Zero-config exclusions**: skips dependency/build/cache dirs uniformly (even without .gitignore), honors .gitignore (root+nested, git and non-git), skips >1MB files; optional `codegraph.json` adds gitignore-style `exclude`, force-in `include`, rank-only `deprioritize` (stays findable, stops outranking first-party code), and custom extension→language mappings that merge over defaults [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **`codegraph affected`: test-file impact for CI**: traces import dependencies transitively from changed source files (stdin-friendly: `git diff --name-only | codegraph affected --stdin`) to select which tests to run [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Installer writes marker-fenced instruction sections**: MCP config plus a fenced section in CLAUDE.md/AGENTS.md/GEMINI.md "because subagents and non-MCP harnesses never see the MCP guidance"; auto-allow permission entries for Claude Code; uninstall reverses everything, leaving project indexes untouched [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]
- **Telemetry**: anonymous usage stats aggregated locally into daily totals before send; opt-in asked at install, `codegraph telemetry off` anytime; ingest endpoint public in-repo enforcing documented field list [VERIFIED-fetched:https://raw.githubusercontent.com/colbymchenry/codegraph/main/README.md]

## Notable absences
No ACL/multi-tenant story — the graph assumes one trusted user per machine (fine for LastHarness's single-env boundary, but no per-department view scoping). No semantic/embedding layer — retrieval is structural + FTS5 lexical; natural-language question routing relies on the agent, not the index (pairs naturally with an external embedding store if ever needed). No incremental garbage collection policy described for deleted symbols beyond incremental sync. License MIT clean; the only egress is opt-in telemetry.

## Feature inventory
- **Local proxy router**: CLI tools point at `http://localhost:20128/v1`; router performs format translation (OpenAI ↔ Claude ↔ Gemini ↔ Cursor ↔ Kiro ↔ Vertex ↔ Ollama ↔ OpenAI Responses), quota tracking, auto OAuth token refresh; dashboard on :20128 [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]
- **Quota-evasion core (the conflict)**: "Maximize subscriptions — Track quota, use every bit before reset"; smart 3-tier fallback Subscription → Cheap → Free with named free-tier pools (Kiro ~50 credits/mo via AWS Builder ID OAuth, "OpenCode Free — No auth • Auto-fetch models", Vertex $300 credits); multi-account round-robin per provider; combos mixing tiers; marketing framing "Never stop coding … $0 cost" [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]
- **RTK Token Saver**: pre-routing compression of `tool_result` content — filters for git-diff/git-status/grep/find/ls/tree/dedup-log/smart-truncate/read-numbered/search-list; auto-detect peeks first 1KB to pick a filter; "Safe by design: if a filter fails, throws, or makes output bigger, RTK silently keeps the original text"; claimed 20–40% input-token savings; runs before format translation so it works across all formats; bypass header `X-9Router-Token-Saver: off` [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]
- **Headroom external compress proxy**: optional `/v1/compress` call before routing; "If Headroom is down or returns an error, 9Router fails open and sends the original request" [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]
- **Prompt-side savers**: Caveman mode (terse-output system-prompt injection, up to 65% output-token claim) and Ponytail ("lazy senior dev" YAGNI ladder Lite/Full/Ultra); both documented as stacking with RTK [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]
- **Self-hosted STT/TTS/embedding providers with no-silent-cloud-fallback guarantee**: whisper.cpp/faster-whisper/Kokoro/vLLM endpoints configured per-connection via `baseUrl`; "**Self-hosted Embedding has no cloud fallback by design** — a connection saved without a `baseUrl` is reported as a configuration error rather than quietly falling back to `api.openai.com`, which would send your input text and API key to a third party under a provider named 'Self-hosted'" [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]
- **Quota telemetry UX**: real-time per-provider token counts, reset countdowns (5-hour/daily/weekly), cost estimation explicitly labeled display-only ("savings tracker"), spending reports [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]
- **Free-tier mortality table**: documents discontinued programs — iFlow now paid (2026), Qwen Code free OAuth tier discontinued by Alibaba 2026-04-15, Gemini CLI shut down 2026-06-18 replaced by closed-source Antigravity CLI; Kiro free tier capped at 50 credits/mo since Sep 2025; OpenCode Free model list fluctuates [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]
- **Cloud Sync of providers/combos/settings** to 9router.com with timeout + fail-fast behavior when cloud DNS unavailable; `REQUIRE_API_KEY` flag recommended for internet-exposed deploys; default `INITIAL_PASSWORD=123456` [VERIFIED-fetched:https://raw.githubusercontent.com/decolua/9router/master/README.md]

## Notable absences
No consent/ToS discussion of subscription-OAuth reuse anywhere in the primary source — the evasion framing is presented as a feature set without acknowledgment of provider terms. No audit log of routing decisions beyond debug request logs (off by default). Health checks are implicit (fallback-on-error) rather than proactive endpoint health probes with circuit-breaker state — despite the ticket's mention, README-level evidence shows reactive failover, not active health checking; the extractable pattern is therefore the failover ORDERING plus fail-open composition above. Free-tier volatility documented honestly, which itself argues against building on such pools.
